# Araça Cloro - Site institucional

Primeira fase do novo site institucional da Araça Cloro Soluções e Serviços.

## Tecnologia

- Next.js com App Router e TypeScript
- Tailwind CSS
- Exportação estática para hospedagem convencional

## Publicação na HostGator

O projeto gera a pasta `out/` durante a compilação. Para publicar, envie o conteúdo dessa pasta para o diretório público do domínio na HostGator. Não há banco de dados, autenticação ou servidor Node.js necessário.

Antes da publicação, confirme o endereço canônico definitivo e substitua a política de privacidade provisória.
